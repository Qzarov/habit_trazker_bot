# Трекер привычек — телеграм-бот

Полезные и вредные привычки, отметки по дням, ежедневные напоминания и календарь месяца картинкой.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Положите токен в `.env`:

   ```
   cp .env.example .env   # и впишите BOT_TOKEN
   ```

3. Запустите:

   ```
   uv run python -m habitbot
   ```

Бот работает, пока запущен процесс (long polling, входящий адрес не нужен). Напоминания приходят
только при работающем процессе; если бот был выключен меньше получаса после назначенного времени,
напоминание придёт при запуске.

## Управление

Всё делается инлайн-кнопками под сообщениями: `/start` показывает меню, на каждом экране есть
кнопка «☰ Меню», экран перерисовывается в том же сообщении. Любой текст вне диалога тоже
открывает меню.

| Кнопка | Что делает |
|---|---|
| 📋 Сегодня | Список привычек с кнопками-отметками за сегодня |
| 📚 Привычки | Карточка привычки: отметка за сегодня и вчера, календарь, напоминание, эмодзи, удаление |
| 🗓 Календарь | Общая картинка месяца: на каждом дне значки всех отмеченных привычек, листание месяцев |
| ➕ Добавить | Название → полезная или вредная → эмодзи → время напоминания (или без него) |
| 🌍 Часовой пояс | Выбор города кнопкой, либо название (`Europe/Berlin`) или смещение (`+3`) текстом |
| ❓ Помощь | Короткая справка |

Время напоминания и эмодзи выбираются кнопками; своё время (`21:30`) и свой эмодзи можно
прислать сообщением.

## Как считаются отметки

- **Полезная**: отметка — «сделано». В календаре зелёный день — сделано, серый — пропуск.
- **Вредная**: отметка — «было» (сорвался). Красный день — было, зелёный — не было.
- На отмеченных днях в календаре стоит эмодзи привычки.
- Дни до заведения привычки и будущие не закрашиваются; сегодняшний без отметки — тоже,
  он ещё не закончился.
- Серия: у полезной — сколько дней подряд отмечено, у вредной — сколько дней подряд без срыва.
- **Правка прошлых дней**: под календарём кнопка «Изменить отметки» открывает сетку дней
  месяца — нажатие ставит или снимает отметку. Доступны дни от заведения привычки до сегодня.

## Общий календарь

Одна картинка на месяц по всем привычкам сразу. В клетке дня — значки привычек, отмеченных в
этот день: полезная на зелёной плашке (сделано), вредная на красной (было). В клетку помещается
шесть значков, дальше показывается «+N». Под сеткой — легенда с числом отмеченных дней за месяц.
Листать можно от месяца самой ранней привычки до текущего.

## Эмодзи на картинке

Эмодзи берутся из системного шрифта: Apple Color Emoji на macOS, Noto Color Emoji на Linux
(`apt install fonts-noto-color-emoji`). Если шрифта нет, календарь рисуется без эмодзи, цветом.
Составные эмодзи (флаги, семьи) не поддерживаются — бот попросит выбрать другой.

## Устройство

- `habitbot/db.py` — SQLite: пользователи, привычки, отметки; расчёт серии.
- `habitbot/bot.py` — команды и кнопки (aiogram 3).
- `habitbot/reminders.py` — цикл напоминаний раз в 30 секунд, по часовому поясу пользователя.
- `habitbot/calendar_image.py` — картинка календаря (matplotlib).

Данные лежат в файле `habits.db` (путь меняется переменной `HABIT_DB`). Состояние диалога
(«жду название») хранится в памяти и сбрасывается при перезапуске — отметки при этом не теряются.
