# Трекер привычек — телеграм-бот

Полезные и вредные привычки, отметки по дням, ежедневные напоминания и календарь месяца картинкой.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Положите токен в `.env`:

   ```
   cp .env.example .env   # и впишите BOT_TOKEN
   ```

3. Запустите:

   ```
   uv run python -m habitbot
   ```

Бот работает, пока запущен процесс (long polling, входящий адрес не нужен). Напоминания приходят
только при работающем процессе; если бот был выключен меньше получаса после назначенного времени,
напоминание придёт при запуске.

## Команды

| Команда | Что делает |
|---|---|
| `/add` | Добавить привычку: название → полезная или вредная → время напоминания (или без него) |
| `/today` | Список привычек с кнопками-отметками за сегодня |
| `/habits` | Карточка привычки: отметка за сегодня и вчера, календарь, напоминание, удаление |
| `/tz` | Часовой пояс: название (`Europe/Moscow`) или смещение (`+3`) |
| `/cancel` | Отменить ввод |

## Как считаются отметки

- **Полезная**: отметка — «сделано». В календаре зелёный день — сделано, серый — пропуск.
- **Вредная**: отметка — «было» (сорвался). Красный день — было, зелёный — не было.
- Дни до заведения привычки и будущие не закрашиваются; сегодняшний без отметки — тоже,
  он ещё не закончился.
- Серия: у полезной — сколько дней подряд отмечено, у вредной — сколько дней подряд без срыва.

## Устройство

- `habitbot/db.py` — SQLite: пользователи, привычки, отметки; расчёт серии.
- `habitbot/bot.py` — команды и кнопки (aiogram 3).
- `habitbot/reminders.py` — цикл напоминаний раз в 30 секунд, по часовому поясу пользователя.
- `habitbot/calendar_image.py` — картинка календаря (matplotlib).

Данные лежат в файле `habits.db` (путь меняется переменной `HABIT_DB`). Состояние диалога
(«жду название») хранится в памяти и сбрасывается при перезапуске — отметки при этом не теряются.
